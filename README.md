# Fixora

The next-generation GSM remote servicing infrastructure, firmware repository, and IMEI intelligence portal.

## Overview

Fixora provides high-velocity server authorization, authenticated OEM flashing, and diagnostics tools for mobile repair technicians, lab engineers, and distributors worldwide.

### Key Capabilities
- **GSM Remote Server Services**: Direct remote USB authorization for Xiaomi Mi Auth, Samsung FRP direct removal, Transsion MDM, and carrier unlocking.
- **Official Firmware Repository**: 240,000+ verified factory stock ROMs, Odin binaries, and unbrick packages with cryptographic integrity checks.
- **GSX & IMEI Intelligence**: Real-time carrier lock detection, iCloud/FMI status, and GSMA blacklist verification.
- **Technician Toolkit**: Signed USB over IP drivers, COM port redirectors, and automated Fastboot utilities.
- **Dynamic Liquid Lava Lamp Engine**: High-performance cyber aesthetic UI with real-time SVG filters and frosted glassmorphism.

## Tech Stack
- **Frontend**: React 18, Vite, React Router DOM, Lucide React, Custom CSS Design System
- **Backend**: Node.js & Express server services
